Thread-safe middleware that returns HTTP 429 on burst traffic, with per-IP token refill at a configurable rate.

Customize your setup.

Everything built from scratch.

Every layer of this server — from TCP socket parsing to HTTP response framing — is implemented without a single external library.

🔌
Raw TCP Sockets
Connection lifecycle, buffering, and framing handled entirely via Python's `socket` module.
🧵
Dual Concurrency
Toggle between thread-per-connection and non-blocking selector event loop at runtime.
🚦
Rate Limiting
Token bucket with per-IP tracking, Retry-After headers, and middleware bypass for internal traffic.
♾️
Keep-Alive Connections
Full HTTP/1.1 persistent connection support with idle reaping in both concurrency modes.
📡
WebSocket Upgrade
Hand-rolled WebSocket handshake and frame parsing supporting text message broadcasting.
🎞️
Byte-Range Streaming
HTTP 206 Partial Content with `Range` header support for video scrubbing and resumable downloads.
📊
SSE Telemetry
Push live memory, thread count, and visit metrics to the dashboard via Server-Sent Events.
🔐
Signed Sessions
HMAC-SHA256 signed session cookies for tamper-proof visit tracking, no external crypto libs.
🧪
Full Test Suite
Unit and concurrency integration tests with zero-dependency AST-based import verification.
